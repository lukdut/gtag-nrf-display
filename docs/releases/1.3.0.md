# GTag Display 1.3.0

Стабильный выпуск с поддержкой **D1 mini на ESP8266** (4 МБ flash, питание
от USB). Экран подключается к Home Assistant через ESPHome Native API;
доступны все существующие макеты и четыре шаблона с рендерингом на устройстве.

## Изменения

- D1 mini добавлена в мастер подготовки YAML в HA. Выпуск содержит
  `gtag-d1-mini-wifi.yaml` и автономный архив `gtag-d1-mini-wifi-esphome.zip`.
- Драйвер Wi-Fi общий для ESP32 и ESP8266. Постоянные буферы кадров занимают
  8 КиБ вместо 12; RAW декодируется сразу в буфер следующего кадра.
- Шрифты и заставка ESP8266 хранятся во flash. Чтение через PROGMEM и
  передача управления Wi-Fi позволяют использовать существующие шаблоны.
- Повреждённый пакет не заменяет последний проверенный кадр.
- Мастер, публичные YAML и внешние компоненты закреплены на `v1.3.0`.

## Установка и обновление

Обновите **GTag Display** через HACS и перезапустите HA. Для ручной установки
распакуйте `gtag-ha-integration.zip` в `/config/` с заменой файлов.

Для D1 mini выберите **GTag Display → Подготовить прошивку → D1 mini ESP8266 →
Wi-Fi**, проверьте GPIO и параметры сети, затем соберите YAML в ESPHome
Device Builder. Первая установка выполняется по USB, дальнейшие — через OTA.
Добавьте плату в штатную интеграцию **ESPHome**, затем в **GTag Display →
Wi-Fi (ESPHome)**. Проверенные версии окружения: ESPHome 2026.9.0 и
Home Assistant 2026.9.2.

По умолчанию: DIO=D2/GPIO4, CLK=D1/GPIO5, CS=D6/GPIO12, RESET=D5/GPIO14.
Сохраните штатные питание LCD и DisplayCLK/S1, соедините земли.
[Подключение и установка D1 mini](https://github.com/lukdut/gtag-nrf-display/blob/v1.3.0/docs/esp8266-wifi.md).

Существующие экраны nRF52840 и ESP32-C3 не требуют перепрошивки ради
добавления новой платы. При обновлении прошивки сохраните GPIO, настройки
сети и ключи API/OTA. Протокол обмена с HA совместим с предыдущим выпуском.
Готовый универсальный BIN для Wi-Fi не публикуется: он собирается с вашими
параметрами подключения.

## Проверки

На физической D1 mini с `1.3.0-dev.1` проверены USB-запись, Wi-Fi,
зашифрованный API, полный RAW-кадр, RLE, четыре шаблона с эталонными CRC,
отклонение повреждённого кадра и зашифрованное OTA при двух клиентах API.
После OTA проверены повторное подключение и запись шаблона; пользователь
подтвердил изображение на LCD. В стабильном выпуске версия прошивки изменена
на `1.3.0`.

Автоматические проверки релиза включают тесты интеграции и протоколов,
сборку ESP8266/ESP32-C3, HA Container на amd64/arm64 и сборки nRF52840.
Длительная работа D1 mini, запас свободной кучи, потеря Wi-Fi и полный
сценарий D1 mini в установленном HA требуют отдельной проверки.
[Результаты и границы проверки](https://github.com/lukdut/gtag-nrf-display/blob/v1.3.0/docs/testing.md).
