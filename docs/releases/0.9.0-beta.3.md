GTag Display 0.9.0-beta.3: контроль актуальности изображения, восстановление Zigbee-связи,
переназначение GPIO и настройка точности показателей.

## Изменения

- Плата сама показывает значок устаревших данных, если HA перестал подтверждать
  актуальность. Значок 24×24 инвертирует фон; срок задаётся в HA, 0 отключает контроль.
  Ненулевой срок должен покрывать минимум два интервала обновления.
- Неизменный кадр подтверждается короткой командой без повторной передачи пикселей.
- Zigbee-устройство автоматически возобновляет поиск сохранённой сети после
  длительной потери связи, в том числе после 200-секундного лимита Nordic SDK.
- DIO, CLK, CS, RESET и вход АЦП настраиваются в ESPHome с проверкой конфликтов GPIO.
- Добавлены отдельный профиль Super52840 и пакет отключения измерения напряжения.
  Вариант без АЦП не создаёт датчик батареи в Zigbee2MQTT и HA.
- Для каждого показателя можно выбрать 0–6 знаков после запятой или исходное значение.
  Округление влияет только на экран и предпросмотр; перепрошивка для этой настройки не нужна.
- Проверена работа двух Zigbee-экранов с разными показателями, сохранение настроек
  после перезапуска HA/Zigbee2MQTT и восстановление одной платы после отключения,
  пока вторая продолжает обновляться.

## Обновление

В HACS: **GTag Display → ⋮ → Redownload → Need a different version? →
v0.9.0-beta.3**, затем перезапустите HA. При необходимости выполните **Update information**.
Для ручной установки распакуйте `gtag-ha-integration.zip` в `/config/` с заменой файлов.
Записи интеграции и настройки экранов сохраняются.

При переходе с beta.1 обновите также прошивку и `gtag-display.mjs` в Zigbee2MQTT.
Согласование возможностей со старыми прошивками запланировано перед стабильной
0.9.0; эта бета рассчитана на согласованные версии интеграции, конвертера и прошивки.
Для Pro Micro / nice!nano используйте `gtag-zigbee.uf2`, для Super52840 —
`gtag-super52840-zigbee.uf2`: у них разные загрузчики и адрес начала приложения.
Последние проверенные локальные сборки уже содержат тот же код прошивки.
При сохранении профиля сопряжение Zigbee не сбрасывается.

Конфигурации ESPHome закреплены на `v0.9.0-beta.3`. Версия beta.2 оставалась
локальной подготовкой; её изменения включены в этот выпуск.

## Файлы

| Файл | Назначение |
|---|---|
| `gtag-ha-integration.zip` | Интеграция HA для ручной установки |
| `gtag-zigbee.uf2` | Основная плата Pro Micro / nice!nano, Zigbee, S140 v6 |
| `gtag-super52840-zigbee.uf2` | Дополнительная Super52840, Zigbee без АЦП, S140 v7 |
| `gtag-display.uf2` | Существующий Bluetooth-профиль Pro Micro / nice!nano |
| `gtag-*.yaml` | Конфигурации для ESPHome Device Builder |
| `*-esphome.zip` | Автономные исходники для сборки без GitHub-пакета |
| `gtag-display.mjs` | Внешний конвертер Zigbee2MQTT |
| `SHA256SUMS` | Контрольные суммы файлов |

Основная цель дальнейшего релиза — **Zigbee2MQTT и Pro Micro / nice!nano**.
Super52840 использовалась для проверки второго экрана. Измерение её потребления,
длительный прогон и дополнительные физические проверки Bluetooth исключены
из критериев выпуска по решению владельца проекта; эти проверки не заявляются выполненными.
Существующие профили и автоматические проверки сохранены.

Проверено с HA **2026.9.2**, ESPHome **2026.9.0**, NCS **2.9.2**, Zigbee2MQTT **2.12.0**.
Автоматические проверки: **131 тест HA, 34 теста прошивки/UF2,
25 тестов конвертера, 5 тестов конфигурации ESPHome**.
