# GTag Display 1.2.0

Простые макеты теперь могут отрисовываться на устройстве: вместо полного
изображения HA передаёт идентификатор шаблона и готовые строки.

## Изменения

- Новый макет **«Три показателя или текст»** с настраиваемым заголовком
  по центру. Каждое поле — сущность HA или обычный текст.
- Рендеринг на устройстве для часов с датой, одного крупного показателя,
  часов с двумя показателями и трёх полей. Эти шаблоны отмечены **🌿**.
- Предупреждение **«⚠️ Передача изображения»** в предпросмотре, если текущие
  значения требуют рендеринга в HA. Макет можно применить; подсказка предлагает
  сократить текст или число знаков после запятой.
- Автоматическое согласование кодеков с каждой платой. Старые прошивки,
  неподдерживаемый текст и значения, требующие уменьшения крупного шрифта,
  продолжают получать RAW/RLE. Погода и график передаются изображениями.
- Протокол кадров остаётся версии **1**. CRC, подтверждение LCD и контроль
  актуальности сохранены; существующий кодек трёх полей совместим с dev.1.
- Мастер YAML для Bluetooth, Zigbee и Wi-Fi использует **v1.2.0**.
- В инструкции подключения явно указаны B+/B− для аккумулятора,
  VCC/GND для экрана и встроенный контроллер заряда поддерживаемой платы.
  История версий и проверки вынесены из README.

## Обновление

1. Обновите GTag Display в HACS до **1.2.0** и перезапустите HA.
   При ручной установке распакуйте `gtag-ha-integration.zip` в `/config/`
   с заменой всей папки интеграции, включая `fonts`.
2. Для Zigbee замените внешний конвертер на **`gtag-display.mjs`** этого
   выпуска и перезапустите Zigbee2MQTT.
3. Обновите прошивку платы до **1.2.0**. Если собираете через ESPHome,
   замените ссылки на пакеты в сохранённом YAML на **v1.2.0**, сохранив свои
   GPIO, загрузчик и настройки батареи. Для ESP32 сохраните также сеть,
   ключ API и пароль OTA.

Одного обновления HA недостаточно для рендеринга на устройстве.
Все экраны не обязательно перепрошивать одновременно: прежние прошивки
сохраняют передачу изображений. Сопряжение и настройки макетов сохраняются.

Готовые `gtag-zigbee.uf2` и `gtag-display.uf2` предназначены для Pro Micro /
Super Mini / nice!nano со стандартной распиновкой и **включённым измерением
батареи через внешний делитель**. При отключённом измерении или других GPIO
соберите свою прошивку через мастер YAML либо из архива `*-esphome.zip`.
Для Super52840 предусмотрен отдельный UF2; профиль без измерения батареи.
Для ESP32 публикуются исходники и YAML, без BIN с настройками сети.

## Проверка режима

В диагностике ожидаются `firmware_version: 1.2.0`, маска кодеков **15**,
`three_values_v1` и `simple_templates_v1` в списке возможностей.
Три поля используют **`codec: 2`**, остальные простые шаблоны — **`codec: 3`**,
если текущие значения подходят для рендеринга на устройстве.
