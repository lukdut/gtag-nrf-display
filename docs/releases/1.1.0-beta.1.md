# GTag Display 1.1.0-beta.1

Первый предварительный выпуск с **ESP32-C3 Super Mini и Wi-Fi** для экрана
с питанием от USB. Стабильным выпуском остаётся **1.0.1**.

## Что добавлено

- Передача изображения через штатное зашифрованное соединение ESPHome в HA.
  Все макеты, предпросмотр, импорт/экспорт и диагностика доступны для Wi-Fi.
- Мастер конфигурации ESP32-C3: GPIO, сеть Wi-Fi, генерация ключа API и пароля
  OTA, скачивание готового YAML для ESPHome Device Builder.
- Первая прошивка через USB, дальнейшие обновления через стандартный OTA ESPHome.
- Дополнительные компоненты ESPHome в пользовательском YAML. Есть пример
  адресной ленты WS2812 с эффектами на свободном GPIO5.
- RAW и WHITE_RLE_V1, проверка CRC32 и подтверждение после завершения записи
  изображения на LCD. Независимые соединения для нескольких устройств.
- Согласование возможностей прошивки, значок устаревших данных и восстановление
  полного кадра после перезапуска платы.

## Установка и обновление

В HACS выберите **1.1.0-beta.1** среди предварительных выпусков GTag Display
и перезапустите Home Assistant. При ручной установке используйте
`gtag-ha-integration.zip`.

Для ESP32 следуйте [инструкции по подключению, USB и OTA](https://github.com/lukdut/gtag-nrf-display/blob/v1.1.0-beta.1/docs/esp32-wifi.md):
подготовьте экран, создайте YAML, соберите и прошейте плату, добавьте её
сначала в интеграцию **ESPHome**, затем в **GTag Display → Wi-Fi (ESPHome)**.
Питание штатной платы экрана и тактирование DisplayCLK/S1 должны сохраняться.

**Для существующих nRF52840 перепрошивка, пересопряжение и замена конвертера
Zigbee2MQTT не требуются.** Их прошивка сохраняет версию **0.9.0**, настройки
интеграции и макеты сохраняются. Мастер nRF52840 использует проверенный тег
v0.9.0; публичные YAML этого выпуска закреплены на v1.1.0-beta.1.

## Файлы выпуска

- `gtag-ha-integration.zip` — интеграция HA со всеми тремя транспортами.
- `gtag-esp32-c3-wifi.yaml` — конфигурация с пакетом этого выпуска.
- `gtag-esp32-c3-wifi-esphome.zip` — автономные исходники ESPHome и пустой
  шаблон секретов. Готовый BIN для ESP32 не публикуется: прошивку нужно
  собрать со своими данными сети, GPIO и дополнительными компонентами.
- UF2, YAML и исходники для прежних профилей nRF52840, конвертер Zigbee2MQTT,
  лицензия MIT и контрольные суммы `SHA256SUMS`.

## Проверки и ограничения

Автоматические проверки охватывают протокол LCD, декодирование и CRC,
устаревание кадра, конфигурацию ESPHome, мастер HA, подтверждения передачи
и независимую работу двух Wi-Fi-устройств. Собирается ESP32-C3 с шифрованием
API, OTA и эффектами WS2812. Выпуск также проходит существующие проверки
Bluetooth/Zigbee, HA Container и сборки nRF52840 на amd64/arm64.

Проверенные версии ПО: **HA 2026.9.2**, **ESPHome 2026.9.0**,
**Zigbee2MQTT 2.12.0**. Wi-Fi-профиль рассчитан на USB-питание;
измерение аккумулятора и глубокий сон в нём не предусмотрены.

**Физическая проверка ESP32-C3 ещё предстоит:** изображение на экране,
одновременная работа ленты, OTA, отключение Wi-Fi и восстановление после
перезапуска платы/HA. Поэтому выпуск помечен как beta.
