Первый публичный релиз GTag Display для nRF52840 Pro Micro / nice!nano.

- Установка интеграции через пользовательский репозиторий HACS
  `https://github.com/lukdut/gtag-nrf-display`.
- Сборка в ESPHome Device Builder из короткого YAML: компоненты автоматически
  загружаются из GitHub, пакет и исходники закреплены на `v0.8.0`.
- Готовые макеты, шаблоны HA, кириллица, предпросмотр с белым фоном,
  автоматические обновления и отдельные настройки каждого экрана.
- Измерение LiPo через делитель 1 МОм / 1 МОм на P0.31 и конденсатор 100 нФ,
  быстрые повторы первого чтения и восстановление после устаревшего BLE-кэша.

Поддерживается Bluetooth. Zigbee через Zigbee2MQTT запланирован, но пока
не реализован. Сборку выполняет ESPHome; собственного сервиса сборки нет.

Радиопротокол и драйвер платы соответствуют проверенной версии 0.7.1.
Для перехода с неё на HACS достаточно обновить интеграцию и перезапустить HA;
перепрошивка устройства и удаление его из HA не требуются.

`gtag-display.uf2` — прошивка для указанной платы и распиновки.
`gtag-ha-integration.zip` — ручная установка интеграции в `/config/` HA.
`SHA256SUMS` — контрольные суммы двух файлов.

Сборка закреплена на ESPHome 2026.8.2 / nRF Connect SDK 2.9.2.
Интеграция программно проверена на Home Assistant 2026.9.2.
BLE, вывод на экран и правильность показаний аккумулятора подтверждены на
плате пользователя. Отдельная проверка установки через HACS и сборки в
ESPHome Device Builder на пользовательских HA OS / HA Container ещё требуется.
