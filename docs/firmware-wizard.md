# Мастер конфигурации прошивки

Мастер доступен начиная с интеграции **1.0.0**.
Он находится внутри интерфейса Home Assistant и создаёт полный YAML устройства.
Сборку и скачивание UF2 выполняет **ESPHome Device Builder 2026.9.0**.

## Установка

[Установите или обновите интеграцию через HACS](installation.md#интеграция-через-hacs)
и перезапустите HA. При ручной установке распакуйте `gtag-ha-integration.zip`
в `/config/` с заменой файлов. Перепрошивка работающих экранов не требуется.

В 1.0.1 прошивка не изменилась: мастер закрепляет YAML на проверенном
теге **v0.9.0**, а плата сообщает версию прошивки **0.9.0**. Версия интеграции
и версия прошивки могут отличаться; возможности согласовываются с каждой платой.

## Где открыть

**Настройки → Устройства и службы → Добавить интеграцию → GTag Display →
Подготовить прошивку (YAML для ESPHome)**.
Если интеграция уже установлена, используйте **Add entry / Добавить запись**
на её странице. Мастер доступен до подключения первого экрана; Bluetooth,
MQTT, Supervisor и ESPHome на машине с HA для подготовки YAML не нужны.
Он не создаёт устройство или лишнюю запись интеграции.

## Шаги

1. Выберите плату и способ связи, задайте уникальное имя конфигурации ESPHome
   и отображаемое имя. Для Pro Micro / Super Mini / nice!nano поддерживаются
   Bluetooth и Zigbee; для Super52840 — Zigbee. Профили рассчитаны соответственно
   на загрузчики S140 6.x и S140 7.x — сверяйте их со своей платой.
2. Проверьте четыре GPIO LCD и укажите, подключён ли внешний делитель батареи.
   При выборе другой платы подставляется её распиновка; каждый вывод можно изменить.
   Проверяются номера GPIO, зарезервированные выводы и пересечения сигналов.
   Штатные питание LCD, общая GND и тактирование DisplayCLK/S1 сохраняются.
3. При включённом измерении укажите вход АЦП, калибровку, пороги отключения,
   полного заряда и восстановления, а также наличие полоски заряда.
   Должно выполняться `empty_voltage < recovery_voltage <= full_voltage`.
   Вход АЦП не может совпадать с сигналами LCD.
4. Нажмите **Скачать …yaml**. Ссылка скачивает файл, сохраняя открытый мастер.
   Она действует 20 минут; её можно обновить действием «Обновить ссылку».
   YAML также показан для копирования.
   «Изменить параметры» возвращает к выбору платы с сохранением введённых данных.
5. В ESPHome Device Builder выберите **Create device → Advanced set up options →
   Import from file** и загрузите YAML. Запустите **Install → Advanced options →
   Download firmware binary** (в прежнем интерфейсе — **Manual download**),
   скачайте UF2 и скопируйте его на USB-диск загрузчика платы.
   **[Установка ESPHome и прошивка со скриншотами](esphome-flashing.md)**,
   включая отдельный ESPHome Container для HA без Supervisor.
   Для Zigbee установите конвертер из того же релиза.
6. Выберите «Завершить и показать ссылку на файл» и нажмите **Submit**.
   На завершающем экране ещё раз появится ссылка **Скачать …yaml**. Submit
   завершает мастер; файл скачивается нажатием ссылки. После завершения ссылка
   доступна ещё 20 минут, до перезапуска HA. При отмене незавершённого мастера
   ссылка удаляется. После прошивки добавьте устройство
   в GTag Display через Bluetooth или Zigbee2MQTT и настройте его макет.

Полученный YAML закреплён на прошивке **v0.9.0**. Он содержит настройки
загрузчика, GPIO и батареи явно. Если измерение выключено, поля АЦП не выводятся;
для Zigbee автоматически подключается пакет без батареи, убирающий её endpoint.

Параметры относятся к внешнему делителю **1 МОм / 1 МОм, 100 нФ**.
Встроенный делитель Super52840 имеет другое соотношение и этим профилем
не поддерживается. [Подробная конфигурация и работа защиты](device-configuration.md).

## Проверки

Автоматические тесты проходят настоящие диалоги HA и HTTP-скачивание файла:
проверяют ошибки полей, редактирование, истечение ссылки, скачивание после завершения и отмену,
независимость двух мастеров и сохранение настроек уже добавленного экрана.
Тесты frontend проверяют ICU-синтаксис всех переводов, затем форматирование,
Markdown и сохранение ссылки скачивания на обоих завершающих экранах.
Генератор дополнительно проверяется ESPHome с обоими транспортами, профилями
плат, переназначением GPIO и включённой/выключенной батареей.
Мастер не передаёт команды работающим экранам и не запускает сборку автоматически.
